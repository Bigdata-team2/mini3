[1. 라벨링 툴(labelImg) 다운로드]______________________________
 - 접속 : https://github.com/heartexlabs/labelImg
 - 오른쪽 하단에 [Releases] 클릭
 - 중앙 상단 [Binary v1.8.x] 제목 밑에 > "windows_v1.8.1.zip" 클릭하여 다운로드
 - 압출 풀고 > [한글 디렉토리 경로]가 없는 곳에 위치하기
   (3번 이미지 라벨링을 바로 시작하면 됨)


 ** 만약 "source code (zip)"을 클릭하여 다운로드한 경우에는 
  => 아래 2번을 통해 가상환경 생성 후 소스 코드로 실행해야 함(소스 코드 실행 방식임)


[2. 아나콘다에 새로운 가상환경 생성]_____________________________
  - pyqt=5 버전 설치
    >conda install -c conda-forge pyqt=5


  - 아래는 확인 필요
    pyrcc5 -o libs/resources.py resources.qrc
    


[3. 학습시킬 이미지 라벨링하기]__________________________________
  - labelImg.exe 파일을 실행
    -> [추가정보] 클릭
    -> [실행] 클릭


  - Class 정의 : 종속변수 실제 이름
    -> ./data/predefined_classes.txt 파일을 편집기로 Open
    -> 나만의 Class명(종속변수)으로 수정
       => 순서대로 class 번호(0, 1, 2..)가 저장되므로, 
       => 번호 라벨링이 중요한 경우에는 > 작성 순서에 유의 


  - 저장 방식을 YOLO로 변경
    -> [왼쪽 메뉴] > [PascalVOC]를 클릭하여 "YOLO"로 변경
       (클릭하면 자동으로 변경됨)


  - 라벨링할 이미지 디렉토리 정의
    -> [왼쪽 메뉴] > [Open Dir] 클릭(단축키 :Ctrl u)
    -> 라벨링할 이미지 디렉토리 선택
    -> 선택된 디렉토리 내에 이미지 여러개 중 한개 보임


  - 라벨링한 이미지 저장할 디렉토리 정의
    -> [왼쪽 메뉴] > [Change Save Dir] 클릭(단축키 :Ctrl r)
    -> 저장할 디렉토리 선택
    -> 라벨링 이미지와 좌표값 파일이 저장되는 곳임


  - 라벨링 진행을 위한 [단축키]
    -> w : 마우스로 드래그하여 사각(라벨링) 영역 표시할 수 있음
    -> d : 다음 이미지(Next Image)
    -> a : 이전 이미지(Previous Image)
    -> del : 선택된 드래그 사각 영역 삭제하기
    -> [Ctrl ++] : 이미지 확대(Zoom in)
    -> [Ctrl --] : 이미지 축소(Zoom out)
    -> [Ctrl C] : 저장
