1. 표준 폴더 구조 (Recommended Folder Structure)
		YOLOv5는 프로젝트 루트 폴더 아래에 datasets와 yolov5 폴더를 분리하는 것을 권장합니다.

		/yolo_custom_project
		├── /datasets                     # 전체 데이터셋을 담는 상위 폴더**
		│   └── /my_custom_data           # 사용자 데이터셋 이름** (예: my_custom_data)
		│       ├── /images               # 모든 이미지를 모아두는 폴더
		│       │   ├── /train            # 훈련용 이미지 파일 (.jpg, .png 등)
		│       │   ├── /val              # 검증용 이미지 파일
		│       │   └── /test             # 테스트용 이미지 파일
		│       └── /labels               # 모든 라벨(주석) 파일을 모아두는 폴더
		│           ├── /train            # 훈련용 라벨 파일 (YOLO 형식, .txt)
		│           ├── /val              # 검증용 라벨 파일
		│           └── /test             # 테스트용 라벨 파일
		├── /yolov5-master                # YOLOv5 깃 저장소 클론 폴더** (실행 파일(train.py)이 여기 있음)
		│   ├── train.py
		│   ├── val.py
		│   ├── models/yolov5s.yaml(기타 YOLOv5 파일들)
		└── my_data.yaml                  # 데이터셋 경로와 클래스 정보를 담은 YAML 설정 파일**



2. 데이터셋 YAML 파일 작성 (my_data.yaml)
		이 파일은 yolov5-master 폴더와 같은 레벨(루트 경로)에 위치하며, 
		YOLOv5-master에게 데이터셋의 경로와 클래스 정보를 알려줍니다.

		# my_data.yaml

		# 훈련, 검증, 테스트 이미지 경로 지정 (루트 경로: yolov5/를 기준으로 '..' 사용)
		train: ../datasets/my_custom_data/images/train
		val: ../datasets/my_custom_data/images/val
		test: ../datasets/my_custom_data/images/test # 테스트 실행 명령어를 위해 필요

		# 클래스(객체) 수
		nc: 3  # 예: 3개의 클래스 (사람, 자동차, 자전거)

		# 클래스 이름 (순서가 라벨 파일의 인덱스(0, 1, 2)와 정확히 일치해야 함)
		names: ['person', 'car', 'bike']
		
		
		
3. 실행 명령어 (Execution Commands)
		프롬프트창에서 > yolov5-master 폴더 내에서 실행...

		A. 훈련 (Training) 명령어
			yolov5s 모델로 학습을 시작합니다.
			
			- 훈련전 train.py 파일 수정하기
			   -> torch.load 검색 : 검색된 모든 내용을 아래와 같이 수정
         (원본)
				   ckpt = torch.load(weights, map_location="cpu")
				 (수정본)
				   # PyTorch 2.6+ 'Weights only load failed' 오류 방지를 위해 weights_only=False 추가
           ckpt = torch.load(weights, map_location="cpu", weights_only=False)
			
         (원본)
				   d = torch.load(last, map_location="cpu")["opt"]
				 (수정본)
           d = torch.load(last, map_location="cpu", weights_only=False)["opt"]
			
			- 훈련전 utils/general.py 파일  수정하기
			   -> torch.load 검색 : 검색된 모든 내용을 아래와 같이 수정
				 (원본)
            x = torch.load(f, map_location=torch.device("cpu"))
				
				 (수정본)
				    x = torch.load(f, map_location=torch.device("cpu"), weights_only=False)
			
			
			- 훈련전 models/experimental.py 파일  수정하기
			   -> torch.load 검색 : 검색된 모든 내용을 아래와 같이 수정
				 (원본)
            ckpt = torch.load(attempt_download(w), map_location="cpu")  # load
				
				 (수정본)
				    ckpt = torch.load(attempt_download(w), map_location="cpu", weights_only=False)  # load
						
			
				
				>python train.py --data ../my_data.yaml --cfg models/yolov5s.yaml --weights yolov5s.pt --name Notes_yolov5s_custom --project runs/train --cache
				set GIT_PYTHON_REFRESH=quiet

				>python train.py \
						--data ../my_data.yaml \
						# 데이터셋 경로 및 클래스 정보가 담긴 YAML 파일 경로 지정
						--cfg models/yolov5s.yaml \
						# 사용할 모델 구조 파일 지정 (여기선 작은 yolov5s 사용)
						--weights yolov5s.pt \
						# 초기 가중치 파일 지정 (사전 학습된 COCO 가중치 사용)
						--batch 8 \
						# 배치 크기 (GPU 메모리 상황에 맞춰 4, 8, 16 등으로 조절)(생략가능)
						--epochs 200 \
						# 전체 데이터셋을 반복할 횟수 (에포크 수)(생략가능)
						--name Notes_yolov5s_custom \
						# **훈련 결과가 저장될 폴더 이름** (runs/train/Notes_yolov5s_custom 에 저장됨)
						--project runs/train \
						# 훈련 결과의 상위 저장 디렉토리
						--cache \
						# 이미지 파일을 RAM에 미리 로드하여 훈련 속도 향상 (RAM 용량 충분할 때 사용)(생략가능)
						--device 0
						# 사용할 GPU 번호 지정 (0번 GPU 사용). CPU만 사용 시에는 생략

=================================[아래는 YOLOv5 실행 흐름 설명]=====================================

1. 폴더 구조의 일치 (Folder Structure Alignment)
	YOLOv5는 이미지 파일과 라벨 파일이 특정 경로 규칙을 따라야 제대로 작동합니다.

	이미지와 라벨 폴더 이름 일치
		: 이미지 폴더(images/train, images/val, images/test)와 
			라벨 폴더(labels/train, labels/val, labels/test)는 같은 하위 폴더 이름을 가져야 합니다.

	파일 이름 일치
		: images/train/001.jpg에 대응하는 라벨 파일은 반드시 labels/train/001.txt여야 합니다.



2. 데이터셋 YAML 파일에서의 경로 지정 (The Role of my_data.yaml)
	가장 중요한 단계는 --data 인수로 지정하는 데이터셋 YAML 파일(my_data.yaml)을 통해 이미지 파일의 경로를 명확히 알려주는 것입니다.

	YOLOv5는 이 YAML 파일의 train, val, test 항목에 지정된 이미지 폴더 경로를 사용해 다음과 같이 라벨 경로를 유추하여 찾습니다.

	YAML에 지정된 이미지 경로	YOLOv5가 유추하는 라벨 경로
		path/to/my_data/images/train	→ path/to/my_data/labels/train

	즉, 이미지 경로만 YAML 파일에 정확히 넣어주면, 
			YOLOv5는 자동으로 이미지 경로의 'images' 부분을 'labels'로 바꾸어 라벨 파일을 찾게 되는 원리입니다.



<요약>
	YOLOv5가 라벨 파일을 인식하는 순서는 다음과 같습니다.

	train.py --data my_data.yaml 명령어를 실행합니다.

	YOLOv5는 my_data.yaml에서 이미지 경로를 읽습니다 
		(예: datasets/my_custom_data/images/train).

	YOLOv5는 이 경로에서 'images'를 'labels'로 대체하여 라벨 파일의 위치를 유추합니다 
		(예: datasets/my_custom_data/labels/train).

	유추된 라벨 폴더 내에서 이미지와 이름이 동일한(.txt 확장자의) 라벨 파일을 찾아서 사용합니다.
