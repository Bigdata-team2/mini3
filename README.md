## 📝 프로젝트 개요
냉장고 속 재료를 효율적으로 관리하고, 남은 식재료로 만들 수 있는 요리를 추천해주는 **AI + Flutter 기반** 스마트 앱 프로젝트입니다.

## ✨ 주요 기능 (Features)

| 기능명 | 설명 |
|:------|:------|
| 📷 **식재료 인식** | 사용자가 업로드한 사진을 AI 모델이 분석하여 식재료를 자동 식별 |
| 🍳 **레시피 추천** | 인식된 재료 조합을 기반으로 맞춤형 레시피 제안 |

| 🗂️ **재료 관리** | 냉장고 속 재료 목록 및 유통기한 관리 |
| 🔍 **음성/텍스트 검색** | “계란으로 뭐 만들 수 있을까?” 와 같은 자연어 검색 지원 |
| ☁️ **클라우드 동기화** | 여러 기기에서 동일한 데이터 실시간 동기화 |
