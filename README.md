# 🧊 [Mini3 Project] 냉장고털이범  
> **"식재료를 인식하고, 그 재료로 만들 수 있는 레시피를 추천해주는 AI 기반 냉장고 관리 앱"**

---

## 📝 프로젝트 개요
냉장고 속 재료를 효율적으로 관리하고, 남은 식재료로 만들 수 있는 요리를 추천해주는 **Yolo + Flutter 기반** 스마트 앱 프로젝트입니다.  
사용자는 식재료를 촬영하거나 입력하면, AI가 이를 인식하고 적절한 레시피를 자동 추천합니다.

> 📆 개발 기간 : 2025.10.14 ~ 2025.10.20  
> 👥 참여 인원 : 총 7명 (Frontend, Backend, Yolo, DB, Labeling)

## ✨ 주요 기능 (Features)

| 기능명 | 설명 |
|:------|:------|
| 📷 **식재료 인식** | 사용자가 업로드한 사진을 AI 모델이 분석하여 식재료를 자동 식별 |
| 🍳 **레시피 추천** | 인식된 재료 조합을 기반으로 맞춤형 레시피 제안 |
| 🔍 **텍스트 검색** | 사진 외에 텍스트로도 검색 가능하게 해 편의성 제공 |
